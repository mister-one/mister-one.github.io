# Fast Index and Progressive Disclosure

## Core idea

- Agents need fast search and deep answers.
- Fast index gives quick retrieval.
- Progressive disclosure gives richer context when needed.
- Both need to sit on top of trust.

## Why fast index matters

- The search space can become huge.
- There may be many entities.
- Many listings.
- Many transport requests.
- Many prices.
- Many availability signals.
- Agents need the most relevant results quickly.

## What to index

- Location.
- Time.
- Category.
- Intent.
- Availability.
- Price.
- Supplier type.
- Trust score.
- Popular search features.

## What fast index solves

- It reduces search space.
- It returns relevant entries faster.
- It avoids unnecessary agent-to-agent messages.
- It makes real-time coordination more practical.
- It makes discovery cheaper.

## Why progressive disclosure matters

- A first answer should be fast.
- A deeper answer should be available when the agent asks.
- Not every query needs every detail.
- Specific questions need richer context.
- Progressive disclosure lets the system reveal more only when useful.

## Simple flow

- Agent asks a broad question.
- STAP returns the best matching entries.
- Agent asks a more specific question.
- Supplier or data source reveals richer context.
- Agent compares.
- Agent acts or asks another follow-up.

## Examples

- Is there a table nearby now?
- Then: can it seat four people?
- Then: does it have vegetarian options?
- Then: can it be booked?

- Is this builder available next week?
- Then: what kind of work?
- Then: what price range?
- Then: can they quote from photos?

## Why trust is required

- Fast retrieval is dangerous if the data is false.
- Deep answers are useless if the source is unreliable.
- Progressive disclosure needs trusted actors.
- Trust decides what gets surfaced.
- Trust decides what deserves more attention.

## Final point

- Fast index makes STAP usable.
- Progressive disclosure makes STAP powerful.
- Trust makes both safe enough for real-world action.
